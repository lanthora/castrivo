Castrivo 的首个公开测试版本：把电脑变成视频投屏接收器。

### 下载

- Windows x64：下载 `_windows-x64_setup.exe` 安装。
- macOS Apple Silicon：下载 `_macos-arm64.dmg`，拖到 Applications 后打开。
- Linux x64：下载 `_linux-x64.AppImage`，添加执行权限后运行。

应用已包含播放器依赖，无需另行安装 mpv 或 SDL2。连接同一局域网后，
在兼容的视频应用中选择 Castrivo。支持播放、暂停、进度控制、音量和全屏，
并使用新的投屏图标。

### 测试范围

macOS 本机已通过投屏、音视频播放、设备发现和播放控制测试。
macOS ARM64 包以 macOS 11 为最低部署目标；旧系统实际运行尚未验证。
Windows 和 Linux 通过 CI 构建、单元测试和基础启动检查，实际投屏仍欢迎反馈。
macOS 使用临时签名、未公证；Windows 安装包未做发行者签名。
该应用接收视频播放，不提供整屏镜像。部分视频应用可能限制投屏设备或内容。

如遇问题，请提供操作系统、投屏应用及复现步骤：
https://github.com/lanthora/castrivo/issues
